# Storyarr v0.4.5

A new My library bookshelf with a slide-out summary, a loading bar for source searches, and a fix for downloads held after a library switched to copying files.

## Changed

- **A new My library bookshelf.** Smaller covers, so more books fit on screen. Click a book and a summary slides out from the right with its cover, author, series, the formats you have, rating, year, narrator, length and description. Open book page is there too, and Get the ebook or Get the audiobook when one is missing. Covers in My library no longer show Quick add or the in-library tick, because every book there is already yours.
- **Searching sources shows the loading bar** under the header, as other pages do, for as long as the search runs. This applies to a book's Sources tab, Quick add and Settings, Sources. A search that fails does not leave the bar on.

## Fixed

- **Downloads held with "The library destination changed; this repair cannot move an existing import".** If a library's import method changed from hardlink to copy after a download was chosen, connection repair now accepts it, because nothing in the library moves. Any other change to the library still needs a new release choice.

## Database changes

None.
