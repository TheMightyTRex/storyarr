# Storyarr v0.4.2

Choose how often Storyarr's background jobs run.

## New

- **Settings → System → Background work:** Normal, Relaxed (5 times less often), Light (20 times) or Minimal (50 times). A slower pace saves CPU and database work on a small or shared server. Searching for and requesting books are not affected.
- Normal keeps the usual schedule, so nothing changes until you choose another pace. A new pace applies within a minute, without a restart.
- The upgrade wizard offers the setting under New settings.

If you slowed Storyarr down by patching its job schedules, you can remove that patch and choose a pace instead.

## Database changes

One migration runs on first start: `storyarr_0084_background_work` adds a `background_work_settings` table. The upgrade wizard saves a settings backup first.

To go back to v0.4.1, run this in the Storyarr container before switching the image back. It removes only this setting:

```
python -m app.downgrade 0083_operation_lookups
```
