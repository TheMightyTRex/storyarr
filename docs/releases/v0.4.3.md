# Storyarr v0.4.3

New layouts for My library Series and Authors, and for Following.

## Changed

- **Two layouts, one switch.** List and detail (the default) shows the list beside the chosen series, author or follow. List shows one aligned row each. The switch sits next to the search.
- **Saved with your account.** Your layout choice follows you to every browser you sign in on. Viewers can save their own.
- **Everything in the same place.** Each series or author shows its covers, the author's picture beside the name, progress, statuses and actions in fixed positions, so rows line up.
- **Following** shows the chosen follow's bookshelf beside the list, with its status filters and book panel.
- Progress counts released books on every page, so the list and the bookshelf agree.

## Database changes

Migration `storyarr_0085_user_preferences` adds a `preferences` column to `users`. To go back to v0.4.2, run `docker exec storyarr python -m app.downgrade storyarr_0084_background_work` before changing the image. Only saved layout choices are removed.
