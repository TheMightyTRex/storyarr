# Dewarr v0.3.9

This patch improves catalog controls, release matching, sign-in, library imports, and failed-download recovery.

## Catalog and preferences

- Keep dropdowns usable when a custom popover fails, with keyboard, touch, dialog and native-select fallback support.
- Restore Hardcover author and series follows with the provider's edition-list schema and clearer schema-versus-permission errors.
- Recognize Hardcover's `Listened` editions as audiobooks and add consistent format filtering to discovery and saved-book editions.
- Preserve open download-preference sections and unsaved edits during background refreshes and delayed saves. Stale edits still require reloading before they can overwrite newer defaults.

## Matching and import review

- Match catalog-confirmed series prefixes and canonical Roman series positions without relaxing full-title, author or position checks.
- Recognize dotted EPUB packaging and release-group labels while retaining numbered partial-content warnings such as `Sample01` and `Excerpt1`.
- Accept standard IDPF obfuscation of declared EPUB fonts while keeping encrypted book content, unknown algorithms and invalid references held for review. Original EPUB bytes are preserved.
- Include the collection-file identity repair from #69: corroborated book/series evidence can establish a match without accepting ambiguous collection contents.

## Accounts and library imports

- Preserve exact OIDC issuer URLs, including trailing slashes; handle an explicit slash-only correction without transferring identities between different provider realms.
- Add Approver and Requester defaults/group mappings and an administrator-controlled onboarding policy. Preserve edits made during sign-in settings saves.
- Support Grimmory's nested Bookdrop paging responses, including empty queues, with bounded and validated paging.
- Anchor new library publication receipts and locks to a persistent root marker so a root-directory inode change alone does not invalidate an import. Replaced markers and ambiguous legacy receipts remain held for review.

## Download sources and recovery

- Recover associated SABnzbd failed/aborted downloads after the configured grace period, release their capacity slot, and deduplicate replacement attempts.
- Add **Exclude VIP releases** for direct MyAnonamouse searches, including fresh eligibility checks before metadata fetching or wedge handling. The option defaults off and does not enable spending; Prowlarr keeps its own settings.

## Upgrade

Pull `ghcr.io/logabell/dewarr:v0.3.9` or `ghcr.io/logabell/dewarr:latest`, then recreate Dewarr. Images support `linux/amd64` and `linux/arm64`.

- Back up PostgreSQL and configuration before upgrading. Startup applies migration `0080_member_setup`; onboarding remains enabled by default. Downgrade is refused when it would discard new member-setup configuration.
- Stop old workers when upgrading and keep API/worker versions aligned: the new publication marker also changes shared lock identity. See [Storage compatibility](https://github.com/logabell/dewarr/blob/v0.3.9/docs/STORAGE-COMPATIBILITY.md).
- Save the MAM exclusion option and refresh existing searches to apply it. Previously held supported EPUBs can use the normal reinspection path without redownloading.

## Remaining validation limits

Reporter-specific Unraid/cache-mover behavior, KeenDNS configuration and authenticated provider responses remain unverified. Hardcover's reported 49-edition omission is not fully explained; the demonstrated format misclassification is fixed. Unsupported EPUB encryption remains held. No live downloads or account purchases were used in validation.
