# Storyarr v0.4.7

## Fixed

- **Soulseek (slskd) with a read-write API key** ([#1](https://github.com/TheMightyTRex/storyarr/issues/1)). slskd 0.26 shares its download folder only with administrator API keys, so testing the connection with a read-write key failed with a misleading message. Storyarr now checks the key first and says what to do: in slskd, give the key the administrator role, then test again. The Soulseek settings help and the [download clients guide](../DOWNLOAD-CLIENTS.md) show a `slskd.yml` example.

## Database

No database changes. To go back to v0.4.6, change the image tag and recreate the container.
