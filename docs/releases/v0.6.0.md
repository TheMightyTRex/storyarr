# Storyarr v0.6.0

## Added

- **A radio library.** In Settings, Connections, the new **Radio library** section chooses an Audiobookshelf podcast library for radio, its folder, and the same folder as Storyarr sees it. Storyarr reads the library every 15 minutes and shows each episode it holds as **In library**: matched by its BBC programme ID first, then by series and episode number (S20E03), then by a title only one episode has. **Read again** reads it straight away. Make a library of the Podcasts type for radio in Audiobookshelf first.
- **Episode files.** An episode in the radio library names its file, its size and the library in its slide-out.
- **Filing radio,** ready for downloads and sorting in later versions: one folder per show, named like **Show - S20E03 - Title**, with the show, series, episode, first broadcast and station written into a copy of the file. The original is only read, so a seeding download never changes, and nothing is overwritten. Audiobookshelf is then asked to rescan.
- **One logo editor.** **Change logo** uses the same editor for a cover, a file you upload and a logo found online: choose the area, take the shape from lightness or transparency, clean up specks at four strengths, and use a small or medium **eraser** and **paintbrush**, with **Undo last edit** and **Clear edits**.

## Changed

- **My library, Series and Authors on one design.** The list sits beside the chosen series or author, whose pane is its own header: the logo or portrait, the facts, the actions and a fan of covers, with a link to the full page. Radio shows follow the same **List and detail** choice.
- **Nicer scroll bars.** Thin and square, in the border colour on a clear track, on every page, including long author lists. High contrast uses the text colour.

## Fixed

- **Change logo previews.** Uploaded logos and logos found online now show a preview, and **Text colour** and **Accent colour** change it.

## Your settings and the way back

One new choice: the radio library, in Settings, Connections. The database gains tables for the radio library and the episodes in it (storyarr_0089_radio_library). To go back to v0.5.9, run `python -m app.downgrade storyarr_0088_series_logos` in the Storyarr container first, then run v0.5.9. Only the radio library choice and its list of episode files are removed; no audio files are touched.
